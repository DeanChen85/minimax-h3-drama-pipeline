# 🎬 Minimax H3 长视频稳定性与连贯性指南 (v2.7.0)

本指南基于 GitHub 最新社区实测数据，专门解决长视频生成中的**人物崩坏、背景漂移、过渡卡顿及音频模糊**问题。

## 🛠️ 核心节点配置：ComfyUI-H3-Multishot v2.7.0

### 1. 解决“人物崩坏”与“漂游”
*   **`seed_per_shot`**: ✅ **必须开启 (ON)**。
    *   *原理*：实测发现，全片共享一个种子反而会导致面部特征随时间推移而“融化”。每个镜头独立种子能更好地锁定角色 ID。
*   **`continuity`**: 设置为 **`context_pin`**。
    *   *原理*：通过锁定原始 Latent 空间的信息，防止解码后的画面偏差在链条中累积。

### 2. 解决“过渡卡顿”与“背景乱换”
*   **`chain_gain_control`**: 设置为 **`flatten`**。
    *   *原理*：如果不启用，每连接一个镜头，画面纹理会锐化约 1.3 倍，导致后期画面过曝或噪点爆炸。`flatten` 模式能强制统一全片的色彩统计。
*   **`color_level`**: 设置为 **`scene`**。
    *   *注意*：不要使用 `mvgd`，它会在每个连接处产生 29% 的色温暖度跳跃。

### 3. 解决“说话对白不清楚”
*   **音频参考**：在 Director 节点的 `voice_ref` 插槽中加载一段清晰的参考语音（WAV/MP3）。
*   **提示词权重**：加入 `(clear speech:1.3), (articulate voice:1.2)`。

## 📝 导演台 (Director) 操作要点

1.  **首尾帧锁定 (FL2VA)**：
    *   在生成每一个分镜时，务必在 `First Frame` 和 `Last Frame` 都放入同一张角色参考图。这是保持人物不崩坏的物理防线。
2.  **运动描述**：
    *   使用明确的运镜词汇：`slow pan right`, `zoom in slowly`, `static shot`。避免模糊的 `moving`。

## 🚀 自动化长视频流程

1.  准备一个包含多个场景描述的文本文件。
2.  使用 `H3_Seamless_Chain_v2.json` 工作流。
3.  设置 `shot_count = 0`（自动根据脚本分镜）。
4.  开启 `auto_chunk_ffn` 以优化显存占用。
